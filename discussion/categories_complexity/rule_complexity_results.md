# Rule Complexity Across Categories

Rule complexity was operationalized as the **token count of each rule’s original content**, using `tiktoken` with the `cl100k_base` encoding. The analysis included **7,310 rules across 25 second-level categories**, collected from 325 JSON files. Token count measures textual length and serves as a proxy for complexity.

- **Overall comparison:** A Kruskal–Wallis test with tie correction found significant differences across categories: **H(24) = 633.28, p < 0.01**. The overall effect sizes were **η²_H = 0.0836** and **rank ε² = 0.0866**.
- **Pairwise comparisons:** Two-sided Dunn tests with tie correction were followed by **Holm correction across all 300 category pairs**. At α = 0.05, **147 pairs were significant** and **153 were not significant**.
- **Pairwise effect size:** Cliff’s δ describes the difference in token counts between each pair: δ = P(row > column) − P(row < column). Positive values favor longer rules in the row category; negative values favor the column category.

These rank-based tests assess distributional differences rather than arithmetic means. Rules were treated as independent observations; clustering within projects or files was not adjusted for. A non-significant result does not establish equivalence.
