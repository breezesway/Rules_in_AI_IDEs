- Commit Message: Adds fallback MCP server discovery

Improves MCP server discovery by adding a fallback mechanism.

If the language model API is unavailable or fails to register the MCP server, writes a Kiro-specific JSON configuration file to disk.
This allows Kiro IDE to discover and start the server, providing a more robust experience when the VS Code API is incomplete or unavailable.

Also standardizes server script and node command resolution into dedicated functions for reusability.
