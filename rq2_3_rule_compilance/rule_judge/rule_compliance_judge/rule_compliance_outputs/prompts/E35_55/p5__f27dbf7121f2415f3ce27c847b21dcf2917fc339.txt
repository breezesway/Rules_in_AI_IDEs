+  1. **PNG格式优化**：改用`compressionLevel`参数，添加`progressive: true`
+  2. **智能质量控制**：高质量设置时先保存临时文件检查大小，如果变大则自动降低质量
+  3. **完整压缩方式**：实现按文件大小压缩，根据目标大小智能估算质量级别
+  4. **尺寸压缩增强**：为按尺寸压缩添加适中的质量设置
+- **技术细节**：
+  - 使用临时文件机制检查压缩效果
+  - 不同格式使用正确的压缩参数（JPEG用quality，PNG用compressionLevel，WebP用quality）
+  - 添加文件大小保护机制，确保压缩后文件不会意外变大
+
+### 保存位置设置不生效问题修复（2024-12-29）
+- **问题描述**：在应用设置中修改默认保存位置后，工具中实际保存位置未更新
+- **根本原因**：
+  1. 工具组件的useEffect依赖条件错误：`if (isOpen && !saveLocation)`
+  2. 保存位置作为依赖项，一旦设置后就不会再触发更新
+  3. 组件缓存了第一次获取的保存位置，不响应配置变化
+- **修复方案**：
+  1. **修改初始化逻辑**：每次打开工具时都重新获取最新配置
+  2. **移除错误依赖**：从useEffect依赖数组中移除`saveLocation`
+  3. **配置清理机制**：如果用户清空了默认保存位置，工具也相应清空缓存
+- **技术细节**：
+  ```typescript
+  // 修复前（有问题）
+  React.useEffect(() => {
+    if (isOpen && !saveLocation) { // ❌ 条件错误
+      // 获取配置...
+    }
+  }, [isOpen, saveLocation]); // ❌ 依赖项问题
+
+  // 修复后（正确）
+  React.useEffect(() => {
+    if (isOpen) { // ✅ 每次打开都获取
+      // 获取配置并清理旧设置...
+    }
+  }, [isOpen]); // ✅ 只依赖isOpen
+  ```
