This commit introduces a new feature to log the details of each video chunk processed by the `GeminiSummaryWriter`. This provides more granular logging for long videos and is useful for debugging and understanding the summarization process.

Changes include:
- A new `log_chat_chunk` method in `ChatLogger` to save a separate log file for each video chunk.
- The `GeminiSummaryWriter` now calls this method for each chunk of a long video.
- A new unit test has been added to verify the chunked logging functionality.
