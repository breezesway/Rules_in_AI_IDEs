- Commit Message: feat: Add paste-to-add-video functionality

This feature allows you to paste a YouTube link anywhere on the UI to open the 'Add Video' modal with the URL pre-filled.

- Added a global paste event listener to `app.js`.
- The listener validates if the pasted content is a YouTube URL.
- If valid, it opens the 'Add Video' modal and pre-fills the URL.
- The event listener ignores pastes inside input and textarea elements to avoid conflicts.
- Added a `setUrl` method to the `UrlInput` component to facilitate this.
