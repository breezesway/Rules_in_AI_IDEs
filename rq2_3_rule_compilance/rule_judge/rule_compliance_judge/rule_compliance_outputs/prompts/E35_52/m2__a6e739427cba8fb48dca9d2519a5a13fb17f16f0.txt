+### 核心视觉设计原则
+
+#### 1. 层次结构 (HIERARCHY)
+**让重要的事物不可能被错过**
+- **视觉权重**：使用大小、颜色、位置来突出重要元素
+- **信息层次**：主要操作按钮 > 次要操作 > 辅助信息
+- **实践要点**：
+  - 主要操作按钮使用更大尺寸和鲜明颜色
+  - 重要状态信息放在显眼位置
+  - 用户首先需要看到的内容放在视觉焦点区域
+- **设计提示**：问自己"用户首先需要注意什么？"
+
+#### 2. 对比 (CONTRAST)
+**让操作从其他所有内容中脱颖而出**
+- **颜色对比**：使用强烈的颜色对比突出关键操作
+- **大小对比**：重要按钮比普通按钮更大
+- **状态对比**：活跃状态与非活跃状态有明显区别
+- **实践要点**：
+  - 主要操作按钮使用品牌色或高对比度颜色
+  - 错误状态使用红色系，成功状态使用绿色系
+  - 选中状态与未选中状态有明显的视觉差异
+- **设计提示**：在灰度模式下测试，如果仍然有效，说明对比度足够
+
+#### 3. 一致性 (CONSISTENCY)
+**通过让UI可预测来减少思考**
+- **交互一致性**：相同的操作在不同地方表现一致
+- **视觉一致性**：相同功能的元素使用相同的视觉样式
+- **行为一致性**：相似的操作有相似的反馈和结果
+- **实践要点**：
+  - 所有工具使用相同的按钮样式和交互模式
+  - 文件选择、进度显示、错误处理等采用统一的设计模式
+  - 主题切换在所有界面中保持一致的视觉效果
+- **设计提示**：熟悉胜过原创，用户依赖于之前见过的设计模式
+
+#### 4. 接近性 (PROXIMITY)
+**将相关的事物组合在一起**
+- **功能分组**：相关的控件和信息放在一起
+- **视觉分组**：使用空白空间和分割线来分组
+- **逻辑分组**：按照用户的思维模式组织界面元素
+- **实践要点**：
+  - 文件选择区域、设置面板、操作按钮分别成组
+  - 相关的设置选项放在同一个区域
+  - 使用卡片、边框或背景色来视觉化分组
+- **设计提示**：空白是你的主要分组工具，而不是线条或边框
+
+#### 5. 平衡 (BALANCE)
+**均匀分布视觉重量**
+- **对称平衡**：左右或上下对称的布局
+- **非对称平衡**：通过不同元素的视觉重量达到平衡
+- **视觉重量**：大小、颜色、位置都会影响视觉重量
+- **实践要点**：
+  - 模态框内容居中对齐，左右平衡
+  - 按钮组合中主要操作和次要操作的视觉重量平衡
+  - 避免所有重要元素都集中在界面的一侧
+- **设计提示**：做"眯眼测试"，如果一侧明显比另一侧重，需要重新平衡

+  - 卡片内容使用统一的内边距和对齐规则
