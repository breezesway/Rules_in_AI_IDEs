Adds side panel UI with Preact/Vite

Implements a side panel UI using Preact and Vite, accessible via an Activity Bar icon.

This includes:
- A new `side-panel-view-provider.ts` file to register the WebviewViewProvider.
- A `webview-ui/` directory containing the Preact app, built with Vite, that renders the UI in the side panel.
- Updates to documentation to reflect the new UI and associated build/run/verify instructions, dev loop details, and troubleshooting tips.

The UI assets are built into `out/ui/` and loaded via `webview.asWebviewUri`.
