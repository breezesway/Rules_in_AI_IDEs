Adds dependency cruiser integration

Integrates dependency-cruiser to provide automated codebase analysis.

This change introduces a new service that leverages the
dependency-cruiser CLI tool to generate dependency graphs for
JavaScript/TypeScript projects. The analysis runs in the background
and stores the results in a structured JSON format, enabling future
UI components or analysis tools to consume the data.

Includes workspace detection, CLI path resolution, process spawning,
timeout/error handling, and output processing with a versioned envelope.
A manual scan command is also added.
