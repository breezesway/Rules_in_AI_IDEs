feat: implement modular typed route classes for navigation

- Create typed route classes co-located with screen modules for maximum modularity
- Add HomeRoute, LoginRoute, LoadingRoute, and UserDetailsRoute extending AppRoute
- Move route classes from centralized routing/ to respective screen folders
- Update GoRouter redirect logic to use typed routes instead of hardcoded URLs
- Simplify route tests to only test specific implementation (path property)
- Remove centralized routes.dart export file to maintain modularity
- Update steering documentation to reflect new modular structure

All route classes provide type-safe navigation with push(), go(), and replace() methods.
Each screen module is now completely self-contained with its route class.
