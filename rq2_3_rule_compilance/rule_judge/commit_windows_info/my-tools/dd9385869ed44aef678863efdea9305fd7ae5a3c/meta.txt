feat: 实现图片压缩功能（按质量等级压缩）

  - 完善 IPC 通信，添加图片压缩相关 API
  - 扩展 TypeScript 类型定义，支持图片压缩接口

- 🎨 用户界面完善
  - 使用 Electron 原生文件对话框选择图片
  - 文件状态显示（准备就绪、处理中、已完成、处理失败）
  - 支持自定义输出格式和文件名后缀
  - 集成保存位置选择和文件重名处理配置

- 🛠️ 错误处理和用户体验
  - 单文件处理失败不影响其他文件
  - 友好的错误提示和 Toast 通知
  - 自动记录操作历史到历史记录系统
  - 使用 formatFileSize 工具函数格式化文件大小显示

- 📚 文档和规范更新
  - 更新 product.md，记录图片压缩功能的实际实现状态
  - 新增图片压缩开发总结，包含技术挑战和解决方案
  - 扩展 project.mdc 开发规范，添加原生模块集成最佳实践
  - 完善检查清单，涵盖构建配置和功能完整性验证

- Sharp 动态加载: const sharp = await import('sharp'); sharp.default(filePath)
