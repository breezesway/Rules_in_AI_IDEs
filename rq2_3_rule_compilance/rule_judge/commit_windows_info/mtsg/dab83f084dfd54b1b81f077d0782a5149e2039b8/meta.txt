refactor: remove tenant checking from token verification

- Update authentication rule to focus on identity-only validation
- Remove tenant parameter from VerifyToken method signature
- Update authentication interface and implementation
- Remove tenant validation logic from token verification
- Update auth middleware to use identity-only verification
- Update all related tests to match new interface
- Regenerate authentication mock with new signature
- Add gomock dependency for mock generation

This change follows separation of concerns principle:
- Token verification = Identity validation only
- Authorization = Handled separately in middleware, use cases, etc.

Benefits:
- More flexible and reusable token verification
- Cleaner separation between identity and authorization
- Easier to implement different authorization strategies
- Better testability and maintainability

All tests pass and application functionality is preserved.
