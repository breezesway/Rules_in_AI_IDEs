perf: remove redundant JSON marshalling in token service

- Remove duplicate json.Marshal() call in token.Generate() method
  - Eliminate redundant marshalling before Redis.Set() call
  - Let Redis adapter handle JSON serialization internally
  - Remove unused encoding/json import

- Improve performance by eliminating double marshalling:
  - Before: json.Marshal(claims) → redis.Set(data) → json.Marshal(data)
  - After: redis.Set(claims) → json.Marshal(claims) once

- All tests pass, confirming no functional changes
- Maintains backward compatibility and existing behavior
- Follows single responsibility principle - let Redis adapter handle serialization
