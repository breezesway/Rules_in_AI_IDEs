feat: Implement sequential video splitting for long videos

This commit introduces the following changes:

-   Updates the logic in `GeminiSummaryWriter` to process long videos sequentially. Instead of generating summaries for all chunks and then combining them, the new approach processes chunks one by one, feeding the summary of the previous chunks into the prompt for the next one.
-   Updates the unit tests for `GeminiSummaryWriter` to test the new sequential logic.
