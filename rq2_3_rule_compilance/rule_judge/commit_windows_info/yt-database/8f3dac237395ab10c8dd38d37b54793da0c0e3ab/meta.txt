fix: Use MAX_VIDEO_DURATION_SECONDS constant in calculate_video_splits

This commit fixes an issue where the `calculate_video_splits` function
in `video_utils.py` was using a hardcoded value for the maximum chunk
duration instead of the `MAX_VIDEO_DURATION_SECONDS` constant defined
in the application's configuration.

This change ensures that the video splitting logic respects the
configured maximum video duration, making the system more consistent
and easier to configure.
