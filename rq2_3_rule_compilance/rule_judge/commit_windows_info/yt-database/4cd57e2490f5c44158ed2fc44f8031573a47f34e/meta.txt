Expand property-based tests for markdown conversion

This commit expands the property-based testing for the markdown conversion logic to cover a wider range of inputs, including links, tables, and code blocks.

The following changes were made:
- Added `hypothesis` strategies for generating markdown links, tables, and code blocks.
- Added property-based tests to verify that these markdown features are parsed correctly.
- Refined existing strategies to avoid generating invalid inputs that were causing test failures.
- Expanded the table test to validate the content of the parsed table, including the number of rows and columns, and the text within the cells.

These tests will help to catch regressions and edge cases in the markdown parsing logic.
