feat: Implement video splitting for long videos and fetch duration

This commit introduces the following changes:

1.  **Video Splitting:**
    -   A `calculate_video_splits` function has been added to `video_utils.py` to split long videos into overlapping chunks. This is necessary to process videos longer than 45 minutes with Gemini.
    -   The `GeminiSummaryWriter` now uses this function to process long videos sequentially, feeding the summary of the previous chunk into the prompt for the next one.

2.  **Fetch Video Duration:**
    -   The `VideoMetadataExtractor` now fetches the video duration from both the YouTube Data API and web scraping.
    -   The `parse_iso8601_duration` function has been added to `video_utils.py` to parse the duration from the API response and scraped data.

3.  **Tests:**
    -   Unit tests for the video splitting logic have been added to `tests/unit/test_video_utils.py`.
    -   Unit tests for `VideoMetadataExtractor` have been updated to include duration checks in `tests/unit/test_video_metadata_extractor.py` and `tests/unit/test_metadata_extraction.py`.
    -   All related tests have been updated and are passing.
