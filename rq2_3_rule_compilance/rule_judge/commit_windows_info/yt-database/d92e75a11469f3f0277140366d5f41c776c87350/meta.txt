feat: Add support for nested formatting in tables

This commit enhances the markdown to Notion converter with support for nested formatting (bold, italic, links, etc.) within table cells.

The `_parse_table_block` function has been updated to use the `parse_rich_text` function for each table cell, allowing for a richer representation of table content.

Comprehensive unit tests have been added to verify the new nested formatting capabilities and to ensure that markdown formatting is not processed within code blocks.
